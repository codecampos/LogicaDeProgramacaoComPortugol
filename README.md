# Lógica de Programação com Portugol

Repositório com os exercícios das apostilas **Faccat** e **Manzano**, resolvidos em **Portugol**, para estudo e prática de lógica de programação.

## Sobre o projeto

Portugol é uma pseudolinguagem em português, muito usada para ensinar os fundamentos da programação sem a barreira da sintaxe de linguagens como C, Java ou Python. Aqui estão as minhas soluções para os exercícios das apostilas, organizadas por material de origem.

## Como executar

Os arquivos podem ser abertos e executados em qualquer IDE que suporte Portugol, como o **[Portugol Studio](https://portugol.dev/)** (gratuito e multiplataforma) ou o **VisualG**.

1. Clone o repositório:
```bash
   git clone https://github.com/codecampos/LogicaDeProgramacaoComPortugol.git
```
2. Abra o Portugol Studio (ou o VisualG).
3. Abra o arquivo do exercício desejado (`[extensão dos arquivos, ex.: .por ou .alg]`).
4. Execute o programa e teste com diferentes entradas.

## Exemplo

```
programa {
  funcao inicio() {
    escreva("Olá, mundo!")
  }
}
```

## Como usar este repositório para estudar

1. Tente resolver o exercício por conta própria antes de olhar a solução.
2. Compare sua resolução com a daqui e note as diferenças de abordagem.
3. Altere os códigos, teste casos extremos e tente melhorar as soluções.

> As soluções aqui são uma das formas possíveis de resolver cada problema, não necessariamente a única ou a mais eficiente.
